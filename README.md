# 🔢 Counter App

A simple and interactive counter web application built with **HTML**, **CSS**, and **JavaScript**. This beginner-friendly project allows users to increase, decrease, or reset a numerical counter with smooth animations and a clean UI.

---

## 🚀 Features

- ✅ Increase, decrease, and reset the count
- 🎯 Real-time updates with dynamic number display
- ✨ Smooth "pop" animation effect on counter updates
- 🎨 Stylish and responsive design using CSS
- 🧠 Clean, readable JavaScript code — great for beginners

---

## 🛠️ Technologies Used

- **HTML5** – for markup and structure  
- **CSS3** – for layout and styling  
- **JavaScript (Vanilla)** – for interactivity and logic
